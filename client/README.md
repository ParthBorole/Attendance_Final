# AttendSecure - Client Frontend

This is the React frontend application for AttendSecure.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Features
- Smart Geofence verification using Leaflet & GPS
- Front-camera verification with live frame capture
- Dynamic QR code generation & scanning
- Role-based views: Student, Faculty, Administrator
